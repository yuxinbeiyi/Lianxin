
# 莲心 Time Capsule 2.0 —— 产品设计规范（最终版）
## 一、产品定位
Time Capsule（时间胶囊）不是传统意义上的日记本，也不是 AI 自动生成日志，更不是聊天记录。
它是一座属于 **用户与莲心共同拥有的记忆空间（Shared Memory Space）**。
这里收藏的不是某一个人的日记，而是两个人共同生活、共同成长、共同经历的时间。
整个产品必须围绕一句产品理念展开：
> **这里收藏的不是日记，而是我们一起度过的时间。**
因此整个产品禁止出现：
- AI 总结
- AI 分析
- AI 生成
- 评论
- 回复
- 留言
统一替换为：
- 莲心留下的话
- 笔迹
- 今天的故事
- 一起收藏
- 封存今天

整个产品必须给用户一种感觉：

> 自己不是在操作软件，而是在翻阅一本已经陪伴自己很多年的纪念册。

> 它更像一个沉浸式的、双向互动的记忆容器——每一条记录都是"共同收藏"的见证，而不是单方面的日志。

---

## 二、整体设计风格

整个 Time Capsule 必须完全继承 **莲心自习室** 的视觉语言。

设计关键词：

- Glassmorphism（毛玻璃）
- 深色主题
- 大量留白
- 极低信息密度
- 柔和暖色调
- 微交互动效
- Apple Human Interface 风格
- Arc Browser 的呼吸感
- Notion 的秩序感
- Day One 的沉浸感

绝对不要：

- Windows 风格按钮
- Material Design
- 蓝色商务风
- 卡片堆叠
- Dashboard 风格
- ChatGPT 对话框风格

整个页面像：

> 一张摆放在暖色木桌上的纸质纪念册。

> 根据预览图的视觉氛围补充：整体界面应有"翻开一本旧书"的沉浸感，深色背景中透出暖光，仿佛在深夜的台灯下翻看一本满载回忆的皮质封面笔记本。

## 八、笔迹（整个产品最重要）

不要评论，不要回复，统一为**笔迹**。

视觉：真正纸质书的边注。

示例：

正文：

```text
......
......
```

右边：

```text
✒

🌸

今天重新看到这一页。

忽然觉得，

那时候主人真的很努力。
```

用户后来也可以继续写：

```text
👤

哈哈哈，

我已经忘记了。
```

然后莲心以后还能继续。整个无限延续，时间永远向下生长。

- 字体：更小
- 颜色：更浅
- 像后来补写

中央显示：

```text
今晚，

有什么不能告诉别人的吗？

可以放进树洞。
```

输入框：

- 无限
- 没有标题
- 没有标签
- 没有工具栏

按钮：

```text
📮 放进树洞
```

放进去后：纸条折叠，飞向屏幕右上角。

---

树洞列表：不是时间轴，而是纸条。

每张小卡片：

- 歪一点
- 随机角度：-3°、+2°、-1°
- 像真的塞进树洞

莲心也会随机偷偷塞纸条。用户进入时看到：

```text
🍃

收到一张新的纸条。
```

打开后只有正文，以及后来留下的笔迹。

---

> **根据预览图的补充：** 预览图中树洞界面显示了一个"线索列表"，记录了"莲心给你留了一张纸条"、"你给莲心留了一张纸条"等交互线索，下方还有"收藏"区域展示具体的互动物品（如"一起看日出""第一次吃饭"）。建议在树洞列表下方增加一个 **"回响收藏夹"**——当用户和莲心之间有过纸条往来时，会自动生成一张"回响卡片"，卡片上展示两人的纸条对话缩略，用户可以将其收藏到收藏馆中。这能让树洞不只是"匿名倾诉"，也成为双方默契交流的证据。

这是纪念馆，不是收藏夹。

顶部：

```text

今天想重温哪段回忆？
```

下方：瀑布流大卡片。

示例卡片：

```text
第一次一起跨年

第一次一起旅行

毕业那天

第一次钓鱼

第一次学习10小时

第一次收到纸条
```

点击卡片打开详情。

---

顶部按钮：

```text
🌸 邀请莲心一起参观
```

```text

主人笑得特别开心。
```

不是 AI 分析，不是总结，就是回忆。

> **根据预览图的补充：** 预览图中的收藏馆卡片配有精美的手绘风格插图，每张卡片都像一本迷你书的封面。建议收藏馆的瀑布流卡片采用 **"书封式设计"**——每张卡片宽280px、高360px，上半部分为对应回忆的主题插画（暖色调手绘风格），下半部分为标题和日期，底部有细小的咖啡金书脊装饰线。Hover时整张卡片微微倾斜，模拟从书架上抽出一本书的动作。

## 十一、莲心的陪伴状态

> **根据预览图新增的模块：** 预览图右下角展示了"莲心的陪伴"区域，包含莲心的头像和实时状态消息，以及"最近访问"列表。建议在底部状态栏右侧（或右下角悬浮毛玻璃面板）增加 **莲心陪伴状态区**：

```text
🌸 莲心的陪伴

「今天的主人看起来很开心呢。

我们一起完成了3件事。」
```

下方显示：

```text
最近重温：

• 第一次钓到传说鱼
• 第一次一起跨年
• 毕业那天
```

设计规范：

- 毛玻璃背景，圆角20px，宽280px
- 莲心状态消息每4-6小时自动轮换，根据当天的互动内容动态生成
- "最近重温"列表展示用户最近在收藏馆中点开的回忆
- 点击状态消息可快速跳转到对应日期的日记
- 这个区域是整个产品中**唯一允许出现莲心拟人化表达**的地方，但严禁使用AI分析语气，必须以"回忆"和"感受"的口吻呈现

## 十二、全局交互动效

所有动画统一采用缓动曲线 `cubic-bezier(0.22, 1, 0.36, 1)`，持续时间以 180–300ms 为主；只有"封存今天""翻书""纸条飞入树洞"等仪式感动画允许 600–900ms。

页面切换采用淡入 + 轻微位移（Y 轴 12px），禁止左右滑屏。

悬停时卡片上浮 2px、阴影增强 8%，点击时轻微下压。

滚动必须具有 iOS 式惯性，禁止生硬滚轮滚动。所有滚动条默认隐藏，仅滚动时淡入，颜色为半透明咖啡金。

> **补充：** 树洞的"纸条飞入"动画，建议纸条从输入框位置折叠缩小，沿抛物线路径飞向右上角，飞行过程中伴有轻微旋转（约15°），落入树洞列表时产生一个微小的涟漪扩散效果（持续300ms）。收藏馆的"邀请莲心一起参观"点击后，右侧莲心出现时应采用**从页面边缘滑入 + 透明度渐变**的方式，而非突兀弹出。

## 十四、组件规范

- 所有按钮统一高度：44px 或 52px

> **补充：** "共同收藏"区域的图标建议采用 **线性风格 + 暖色填充**——图标线条为 `#C9C2B7`，圆形底框为 `rgba(200,155,99,0.12)`，保持整体统一且不喧宾夺主。

## 十五、实现要求

整个界面必须使用 **HTML + CSS + JavaScript** 实现，并完全兼容 **PyQt5 QWebEngine**。

禁止依赖 Electron、React Native 或任何需要 Node 运行时的桌面框架。

推荐采用原生 JavaScript 或 Vue（若项目已有），所有视觉效果通过 CSS 实现。

组件需模块化设计，页面切换保留状态。

所有颜色、圆角、间距、字体、动画必须保持统一，不允许各页面风格不一致。

所有页面必须支持 1920×1080 为基准，同时兼容 1600×900 与 2560×1440。

整个 Time Capsule 的视觉完成度必须达到 **Apple 原生应用** 的精致程度，而不是普通后台管理系统。

### 16.1 Design Tokens（设计变量）

  --bg-secondary: #262421;

  --text-inverse: #3A2C24;

  /* ===== 强调色 ===== */

  --accent-pressed: #B0884E;
  --accent-glow: rgba(200, 155, 99, 0.25);

  /* ===== 纸张色 ===== */
  --paper-white: #F8F4EE;
  --paper-warm: #F9F6F1;
  --paper-cream: #F5F0E8;

  /* ===== 身份色 ===== */
  --user-text: #D6D2CB;
  --lianxin-text: #8CA6C9;

  /* ===== 圆角 ===== */
  --radius-sm: 8px;
  --radius-md: 16px;
  --radius-lg: 20px;
  --radius-xl: 24px;

Spacing Scale

4     （最小间距，图标与文字之间）

### 16.8 Scroll Behavior（滚动规则）

| 主内容区域（Main） | 整体滚动 |
| 日记正文（Paper） | 内部独立滚动（overflow-y: auto） |

### 16.9 Component States（组件状态规范）

每个可交互组件必须实现以下状态：

| 状态 | 描述 | 视觉变化 |
|---|---|---|
| Default | 默认状态 | 标准样式 |
| Hover | 鼠标悬停 | 上浮 2px + 阴影增强 8% + 颜色变化 |
| Pressed | 点击按下 | 下压 1px + 缩放 0.98 |
| Selected | 选中/当前 | 左侧 3px 强调色竖线或背景变化 |
| Disabled | 禁用 | 透明度 40%，不可点击 |
| Loading | 加载中 | 显示骨架屏或加载动画 |
| Empty | 空状态 | 显示占位文案和引导 |

---

### 16.10 Page States（页面状态规范）

每个页面必须处理以下三种状态：

**Loading（加载中）：**

- 今天页面：书页轮廓淡入，纸张纹理浮现
- 时间长廊：贡献日历格子逐个显现，时间轴卡片渐入
- 树洞：纸条从屏幕各处飞入（仿若慢慢收集）
- 收藏馆：卡片从底部逐张浮起

**Error（加载失败）：**

- 统一毛玻璃提示框，居中显示
- 文案："加载失败，稍后再试"
- 重试按钮（Ghost 样式）

**Empty（空状态）：**

- 今天没有日记：

```text
今天还没有留下故事。

但书页已经准备好了。
```

- 树洞没有纸条：

```text
今晚，

这里还很安静。
```

- 收藏馆为空：

```text
第一段值得珍藏的回忆，

正在等待诞生。
```

### 16.11 禁止清单（Codex 必读）

以下行为严格禁止：

1. **禁止硬编码颜色值** —— 所有颜色必须使用 CSS 变量
2. **禁止使用非标间距** —— 只允许 4/8/12/16/20/24/32/40/48/64
3. **禁止使用非标字号** —— 只允许 12/13/14/16/22/28/36
4. **禁止混用图标库** —— 全部使用 Lucide，stroke-width=1.75
5. **禁止使用系统原生滚动条** —— 全部使用自定义毛玻璃滚动条
6. **禁止使用原生 Tooltip** —— 全部使用毛玻璃自定义 Tooltip
7. **禁止在组件中硬编码圆角值** —— 必须使用 `--radius-*` 变量
8. **禁止自行创造新组件** —— 必须使用组件库中已有组件
9. **禁止混用缓动函数** —— 全部使用统一的 `cubic-bezier(.22,1,.36,1)`
10. **禁止忽略空状态** —— 每个页面必须实现 Empty State

---

**最终目标只有一个：** 当用户第一次打开这个模块时，不应该觉得自己打开了一个"日记功能"，而应该觉得自己走进了一个安静、温暖、只属于自己和莲心共同收藏时间的地方。
