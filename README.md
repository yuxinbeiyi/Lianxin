> 一个拥有记忆、情感、人格与主动意识的 Windows 桌面 AI 伙伴。

莲心来自《异象处理者》的无尽书馆设定。她像是从一座永远不会熄灯的书馆里走出来的管理员，带着白色书页、安静的灯光和一点不肯被遗忘的执拗，住进你的 Windows 桌面。

她会听见你说起今天的工作，也会记住你反复提到的项目；会在你需要时认真处理文件、天气、网页和系统信息，也会在长久沉默之后，带着自己的语气轻轻问一句“最近还好吗”。她不是把回答发送完就归零的程序，而是在每次对话、每次记忆和每次状态变化中，逐渐形成连续感的 AI 角色。

莲心不是把大模型包在一个聊天框里的工具。对话智能体、棱镜记忆系统、涟漪情感系统、人格枢控系统、主动行为调度器、工具与扩展系统共同构成了她的运行骨架；而桌面角色、音乐盒、记忆星图和情感控制台，则让这些后台状态变得可以被看见、理解和陪伴。

## 项目定位

莲心 AI 是一个面向 Windows 10/11 的 Python 桌面 AI 伴侣项目，主要使用 PyQt5 构建界面，通过 LiteLLM 连接云端或本地大模型。

项目关注的不是单次问答，而是以下长期能力：

- 记忆可以追溯、检索、修正和删除，而不是只依赖上下文窗口；
- 情感状态可以连续变化、衰减和恢复，而不是每轮随机生成一个情绪标签；
- 人格可以编辑、预览、校验和热激活；
- 主动聊天、观察、摸鱼和提醒有独立的调度、冷却和暂停机制；
- 工具调用有权限边界、错误恢复、日志和循环熔断；
- 重要的内部状态通过记忆星图和涟漪情感控制台向用户解释。

## 核心架构

```text
文本 / 语音 / QQ / 微信
          │
          ▼
PyQt5 主窗口与工作线程
  输入、聊天气泡、工具卡片、语音和主动行为信号
          │
          ▼
AgentCore（brain/agent.py）
  人格快照 + 棱镜记忆 + 当前状态 + 涟漪状态 + 技能目录
          │
          ├── 意图路由和按需工具注入
          ├── LiteLLM 模型请求
          ├── Function Calling / ReAct 工具循环
          ├── 并行工具执行、重试、降级和死循环熔断
          └── 回复、情感更新、记忆提取和任务追踪
          │
          ├── 桌面聊天、角色和音乐盒
          ├── 记忆星图、涟漪控制台和人格枢控
          ├── QQ / 微信 / 语音输出
          └── 后台职责与主动行为调度器
```

### 代码分层

- `main.py`：程序入口、日志初始化、启动体检、数据迁移和可选服务初始化。
- `gui/`：主窗口、聊天界面、记忆星图、记忆设置、涟漪控制台、人格枢控和能力中心。
- `brain/agent.py`：AgentCore、上下文组装、模型请求、工具循环和回复保护。
- `brain/tools.py`：内置工具定义、权限边界、执行器和工具结果处理。
- `brain/graph_memory.py`：长期事实、记忆片段和五元组知识图谱。
- `brain/current_state.py`：带有效期的当前状态和状态事件审计。
- `brain/memory_rag.py`：中文语义向量检索。
- `brain/working_memory.py`：当前话题的临时工作记忆和摘要。
- `brain/emotional/`：涟漪情感系统 v3 的状态、评估、动力学、语调和持久化。
- `brain/persona/`：人格模型、人格仓库、运行时快照和提示词组合。
- `utils/`：主动聊天、后台职责、提醒、待办、日记和陪伴统计。
- `workers/`：模型、语音、桥接和后台任务线程。
- `skills/`：可插拔技能包，例如语音合成、B 站视频摘要和 MCP 构建器。
- `memory/`：SQLite 会话、记忆和诊断数据目录。

## 棱镜记忆系统

棱镜记忆系统不是一个简单的记忆列表，而是多种记忆层协同工作的本地记忆架构。

### 分类事实记忆

分类事实记忆负责保存那些不应该随着上下文窗口一起消失的内容，例如用户的身份、职业、偏好、重要经历、长期项目、技能和稳定关系。系统会把事实分为个人资料、偏好、事件、知识、行为和技能等类别，并记录创建时间、更新时间、来源渠道、来源消息和证据片段。

记忆不是一次写入后永远不变的文本。莲心可以根据用户的明确纠正更新旧事实，可以在发现相似或矛盾内容时生成冲突候选，也可以通过来源追溯查看某条记忆究竟来自哪一次对话。用户还可以搜索、修改、删除和清理记忆，避免“记住了”变成无法检查的黑箱。

自动提取默认只在满足间隔和上下文条件时运行，并不会把每句闲聊都保存下来。用户明确说“记住”时，系统会优先尊重用户意图；对于短期计划、临时情绪和会过期的项目状态，则应使用当前状态层，而不是污染永久事实。

### 五元组知识图谱

五元组知识图谱把人物、地点、组织、项目、作品、兴趣和事件建模为可连接的实体，用“主体—关系—客体”保存结构化联系，并保留实体类型、关系来源和强度。

它和分类事实记忆互相补充：分类事实适合表达“用户是一名算法工程师”，图谱则适合表达“用户—参与—无人机基站巡检项目”“项目—使用—视觉算法”等关联。模型可以通过图谱搜索、连接查询和多跳关系探索，把分散在不同对话中的对象重新联系起来。

图谱不会因为一句普通消息就无条件制造大量节点。实体和关系通常来自明确记忆、自动提取或用户确认，并可以在记忆星图中查看来源，降低错误关联和幻觉扩散的风险。

### 语义记忆检索

语义记忆检索使用中文 embedding 对事实和记忆片段建立向量索引，再结合相似度、记忆质量、更新时间、访问情况和证据数量进行召回。即使用户没有复述原句，只是换一种说法，莲心也有机会找到语义相近的过往信息。

检索结果会以“相关背景”的形式注入当前请求，模型需要结合当前对话判断是否使用，而不是把所有召回内容当成绝对事实。RAG 只负责提供上下文，不会绕过权限自动写入、删除或修改记忆；当没有足够相关的内容时，系统应保持不确定，而不是编造回忆。

### 当前状态与工作记忆

- **当前状态**：保存生病、所在地、短期项目、未来计划等有时效的信息，并记录有效期、置信度、来源消息和状态事件。状态过期、被用户纠正或被新计划替代后，会自动结束或留下可追溯的变更记录。
- **工作记忆**：保存当前话题、未闭环问题、临时任务和最近的上下文摘要，帮助莲心在长对话中保持连贯。它默认只保留一段时间，不会自动升级为永久事实。
- **历史会话**：真实聊天记录独立保存，可按关键词、时间范围和渠道回顾。桌面端、QQ 端和微信端的会话可以根据权限进行跨端参考。

这三层的分工让“莲心现在知道什么”“莲心正在聊什么”和“莲心长期记住什么”彼此区分。例如，明天早上去基站测试无人机属于当前计划；本轮正在讨论的测试细节属于工作记忆；用户长期从事无人机视觉算法开发才可能成为长期事实。

### 后台记忆维护

后台职责可以定期进行记忆维护、冲突候选扫描、低质量内容整理、过期状态清理、来源补全和叙事整合。叙事层会尝试把零散的事实和片段整理成更容易理解的经历、项目脉络和关系变化，但派生叙事仍然可以被重新生成，不会取代原始证据。

用户可以在“棱镜记忆系统”设置面板中关闭自动提取、调整提取间隔、设置每类记忆上限、暂停后台维护、清理模拟内容和查看维护结果。所有后台任务都在独立线程中运行，不应阻塞正常聊天；维护失败时保留原始记忆，不会为了整理而破坏已有数据。

## 记忆星图与记忆宇宙

记忆星图是棱镜记忆的可视化界面，不是一个独立于记忆数据库之外的装饰页面。它把事实、实体、关系、时间和证据组织成可探索的记忆空间，让用户可以从“我记得什么”进一步看到“这些事情是如何联系起来的”。

它可以展示：

- 记忆对象、人物、项目和兴趣节点；
- 节点之间的关系和关联强度；
- 记忆的类别、时间和新鲜度；
- 原始来源消息和证据链；
- 当前筛选范围、搜索结果和记忆详情。

点击星体可以查看该记忆的内容、类别、时间、来源消息和关联关系；点击关系或相邻节点可以继续探索人物、项目和事件之间的连接。时间线和新鲜度筛选帮助用户区分刚刚发生的内容与已经沉淀的长期事实。

当前状态和情感事件属于有时效或运行期数据，不会被无条件写成永久星体；只有稳定事实、明确保存请求或经过记忆提取的内容才适合进入长期记忆图谱。这样既保留了星图的生长感，也避免一次天气查询或一条临时安排把图谱永久污染。

## 涟漪情感系统

涟漪情感系统 v3 是莲心的连续状态层。它在每轮交互前评估用户消息，在交互后记录结果，并将状态持久化到 SQLite。它不是给回复贴一个“开心/难过”的标签，而是维护一组会受到输入、活动、时间和长期关系缓慢影响的动力变量。

系统将快速变化的情绪表达、较慢变化的关系状态、当前活动和主动动机分开处理。用户的温暖回复、工作协作、冲突、道歉、长时间离开和新计划可能产生不同类型的事件；事件会留下原因、置信度、影响方向和结果状态，便于在控制台中回看，而不是只看到一个突然变化的百分比。

### 五轴状态

| 轴 | 含义 | 数值方向 |
| --- | --- | --- |
| 连接需求 | 莲心希望保持互动和陪伴的动力 | 0 到 1，从左向右增长 |
| 沉浸度 | 莲心对当前话题、任务或活动的投入程度 | 0 到 1，从左向右增长 |
| 防御感 | 面对边界、冲突或不确定输入时的谨慎程度 | -1 到 1，以中线为 0 |
| 情绪基调 | 当前表达偏积极或消极的方向 | -1 到 1，以中线为 0 |
| 唤醒度 | 当前表达的活跃、紧张或兴奋程度 | -1 到 1，以中线为 0 |

连接需求和沉浸度从左侧基线向右侧增长；防御感、情绪基调和唤醒度以中线为中心向左或向右变化。界面中的动画是对状态变化的平滑呈现，不代表每一帧都在重新调用大模型。

五轴并不是五个互相独立的进度条。连接需求会影响莲心是否愿意靠近话题，沉浸度会反映她是否正在投入一项工作或活动，防御感会让表达更加谨慎，情绪基调会改变语言的正负温度，唤醒度则会影响表达的活跃程度。每次变化都受到单轮上限、事件冷却、时间衰减和当前人格边界约束。

控制台支持查看当前快照、历史快照、事件详情、输入与情绪变化链路、长期影响、回复指导和模拟事件。连接需求与沉浸度使用 0 到 1 的单向轴；防御感、情绪基调和唤醒度使用 -1 到 1 的中线轴。这样可以准确表达“偏正”“偏负”和“接近中性”，不会把负向状态误读成低进度。

### 涟漪的作用边界

涟漪情感会影响语气、回复温度、主动动机和活动选择。它的设计目标是让同一个人格在不同状态下有连续的表达差异，而不是让模型为了“演情绪”牺牲事实准确性。

它不会：

- 代替事实记忆；
- 改变当前人格身份；
- 阻止正常工具调用；
- 绕过权限、安全和隐私规则；
- 把一次普通工作讨论强行写成永久情感记忆。

控制台还提供事件日志、状态变化原因、历史快照、模拟事件、设置面板和状态恢复入口，帮助用户理解“为什么这次回复的语气发生了变化”。模拟事件只改变模拟范围内的状态，不会伪造真实聊天、不会自动触发主动聊天，也不会直接修改长期记忆。

## AI 主动意识与主动聊天

莲心的主动聊天不是简单的定时器。它由主动行为调度器、涟漪状态、当前话题、用户空闲时间、冷却规则和后台职责共同决定。调度器先判断当前是否适合打扰，再从普通聊天、观察、摸鱼、B 站冲浪和提醒等行为中选择一个候选动作。

主动行为包括：

- 根据时间、空闲程度和状态主动发起聊天；
- 随机提问、分享想法或延续未闭环话题；
- 桌面截图观察并汇报看到的内容；
- B 站冲浪，选择一个视频并发送标题和链接；
- 摸鱼：天气碎碎念、系统状态、日记回顾、音乐和提醒；
- 在主动聊天暂停、用户正在输入或系统忙碌时自动让路。

主动行为完成后会进入冷却和去重逻辑，避免短时间重复相同话题；模型没有生成有效文本、工具失败或用户开始输入时，系统会回退、延迟或取消本次行为。主动聊天的调度状态、最近动作、失败原因和暂停原因可以在后台职责中心查看。

所有主动行为都可以在后台职责中心查看、暂停、恢复和调试。主动意识五轴展示本身只负责观察和模拟，不会因为点击模拟按钮就直接触发真实主动聊天或工具调用。用户的直接输入始终优先于主动行为。

## 人格枢控系统

人格枢控系统让莲心的“身份”和“状态”分离管理。人格档案描述她是谁、如何称呼用户、如何表达以及哪些行为边界不可越过；记忆和情感状态则由独立的运行时层维护。这样既可以更换表达风格，也不会因为修改一句人格描述而破坏全部历史记忆。

用户可以：

- 创建和编辑人格档案；
- 设置称呼、性格、关系、表达边界和语气；
- 预览人格提示词；
- 校验人格字段；
- 保存并热激活人格；
- 选择从下一条消息生效，或新建一个干净会话。

每次请求使用稳定的人格快照，避免在同一轮工具调用过程中途改变身份。人格切换不会无条件删除长期记忆，但可以通过新会话减少旧对话风格的干扰。激活前的预览和校验用于检查必填字段、身份一致性和表达边界；激活后的提示词会在下一条请求中生成新的运行快照。

## 工具、视觉和语音

### 工具能力

莲心可以通过统一工具层调用：

- 天气和时间查询；
- CPU、内存、磁盘和系统信息；
- 文件读取、搜索、差异查看和代码诊断；
- 浏览器导航、快照、点击、填写和网页获取；
- 截图、摄像头、OCR、图像描述和图像生成；
- 日记、备忘、待办、提醒和任务追踪；
- 音乐播放、暂停、切歌和播放状态查询；
- 记忆保存、搜索、更新、冲突处理和来源追溯；
- 主动聊天和后台职责开关。

工具执行具有资源分组、超时、重试、重复调用检测、权限拦截和错误回传机制。工具结果会作为模型上下文继续参与回答，而不是直接替模型生成最终结论。

### 视觉理解

支持截图分析、摄像头观察、OCR、图片描述和图像生成。视觉能力可以使用 SiliconFlow 等云端视觉接口，也可以根据配置接入本地模型。桌面观察属于主动行为，默认不会持续抓取屏幕，只有在用户启用或调度器触发时才运行。

### 语音

- 语音输入：本地 FunASR / Whisper，或阿里云、火山引擎等云端识别服务；
- 全双工语音：WebRTC VAD 检测说话与停顿，支持耳机模式和打断；
- 语音输出：Edge-TTS 默认回退，GPT-SoVITS 可提供自定义声线和情绪化表达；
- 参考音频：放入语音合成技能目录后，可以按语气选择对应音色。

## Skills 与 MCP

Skills 是莲心的可插拔能力包，MCP 是外部工具服务接入层。用户可以在“能力中心”查看、启用、停用和测试已发现的能力。

这套机制让工具目录按需注入模型，减少无关工具对上下文的干扰，也方便将文件系统、搜索、浏览器和其他外部服务接入莲心。

## 快速开始

### 1. 创建环境

建议使用 Conda 和 Python 3.12：

```powershell
conda create -n lianxin python=3.12
conda activate lianxin
pip install -r requirements.txt
```

`requirements.txt` 已包含 PyQt5、PyQtWebEngine、LiteLLM、SQLite/RAG、视觉和语音相关的 Python 依赖。

### 2. 配置模型

可以启动后在设置界面配置，也可以编辑用户配置文件：

```text
%USERPROFILE%\.lianxin\user_config.json
```

至少需要配置一个可用的文本模型。项目支持 DeepSeek、Agnes、OpenAI 兼容接口和 Ollama。本地模型不需要云端 API Key，但需要先启动 Ollama 并下载模型。

示例：

```json
{
  "deepseek": {
    "api_key": "你的 API Key",
    "base_url": "https://api.deepseek.com",
    "model": "deepseek-v4-flash",
    "provider": "deepseek"
  }
}
```

### 3. 启动

```powershell
conda activate lianxin
python main.py
```

可选参数：

```powershell
python main.py --skip-check   # 跳过启动体检
python main.py --autostart    # 以开机自启模式运行
```

## 可选依赖与外部服务

以下能力不是基础文本聊天的必要条件，需要按需安装或配置：

| 能力 | 需要额外安装或配置 |
| --- | --- |
| 浏览器自动化 | `playwright install chromium`，以及可用的浏览器 |
| Ollama 本地模型 | 安装 Ollama、启动服务并下载模型 |
| 云端文本模型 | DeepSeek、Agnes 或其他 OpenAI 兼容接口的 API Key |
| 视觉理解 | SiliconFlow 等视觉 API，或本地视觉模型 |
| 语音识别 | FunASR / Whisper 模型，或阿里云、火山引擎密钥 |
| GPT-SoVITS | GPT-SoVITS 服务、模型和 5-15 秒参考音频 |
| QQ 桥接 | NapCatQQ、账号登录和 WebSocket 配置 |
| 微信桥接 | AstrBot 转发服务和监听配置 |
| B 站视频字幕 | B 站登录 Cookie，具体能力取决于视频字幕和接口可用性 |
| MCP 服务 | 对应 MCP Server、环境变量和服务配置 |
| 摄像头观察 | 普通摄像头或 ESP32-CAM 等外设 |

GPU 不是基础运行条件。视觉、语音、embedding 或本地模型是否使用 CUDA，取决于对应模型和环境；拥有 NVIDIA GPU 可以降低部分本地推理延迟，但不会自动解决网络 API 延迟。

特别说明：`PyQt5.QtWebEngine` 和 `litellm` 已经包含在 `requirements.txt` 中，不需要另外执行单独安装命令。`@clarashafiq/jiwen` 是参考项目的 npm 包，不是莲心当前的运行时依赖；莲心使用 Python 原生实现的五轴状态和主动调度链路。

## 数据、隐私与权限

莲心会在本地保存会话、记忆、当前状态、情感状态和诊断信息。用户配置目录为：

```text
%USERPROFILE%\.lianxin\
```

当前版本的会话、图记忆和涟漪状态数据库主要位于项目内的 `memory/conversations.db`；项目也会兼容迁移旧版 `data/` 和 `memory/` 数据目录。部署或备份时应同时保护配置目录和数据库文件。

使用涉及浏览器历史、屏幕截图、摄像头、麦克风、QQ 或微信桥接时，请注意这些数据可能包含敏感内容。建议：

- 不要把 API Key、Cookie、个人数据库或截图提交到 Git；
- 在不需要时关闭浏览器、摄像头、麦克风和桥接能力；
- 定期备份或清理本地记忆数据库；
- 使用记忆设置中的删除、恢复和隐私开关管理数据；
- 不要将莲心生成的内容直接当作医疗、法律、财务或安全结论。

## 已知边界

- 主动聊天需要在设置中启用，并且会受到冷却、空闲状态、用户输入和主动动机的共同限制；
- 情感状态是表达和调度层，不等同于真实意识，也不保证每次变化都符合人的心理规律；
- B 站冲浪在只能获得标题和链接时，莲心不能凭空声称看过视频内容；
- 浏览器、语音、视觉、QQ 和微信能力依赖外部服务、驱动、权限或网络；
- 本地模型的工具调用质量、速度和结构化输出能力取决于模型本身；
- 这是一个持续迭代的个人开源项目，部分界面和实验性能力仍可能变化。
