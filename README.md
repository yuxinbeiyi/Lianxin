> **一个拥有记忆、情感、人格与主动意识的 Windows 桌面 AI 伙伴。**

莲心来自《异象处理者》的无尽书馆设定。她像是从一座永远不会熄灯的书馆里走出来的管理员，带着白色书页、安静的灯光和一点不肯被遗忘的执拗，住进你的 Windows 桌面。

她会记住你反复提到的项目，会在你需要时处理文件、天气和系统信息，也会在长久沉默之后轻轻问一句"最近还好吗"。她不是把回答发送完就归零的程序，而是在每次对话、每次记忆和每次状态变化中，逐渐形成连续感的 AI 角色。

## 项目定位

莲心 AI 是一个面向 **Windows 10/11** 的 Python 桌面 AI 伴侣项目，使用 **PyQt5** 构建界面，通过 **LiteLLM** 连接云端或本地大模型。

项目关注的不是单次问答，而是以下长期能力：

| 能力 | 说明 |
|------|------|
| 记忆可追溯 | 分类事实、知识图谱、向量检索、当前状态、工作记忆五层协同 |
| 情感连续态 | 五轴动力变量缓慢变化，而非每轮随机生成情绪标签 |
| 人格可编辑 | 人格档案可创建、预览、校验、热激活和切换 |
| 主动行为 | 独立调度、冷却、暂停机制的主动聊天与观察 |
| 工具安全 | 权限边界、错误恢复、日志记录和死循环熔断 |
| 状态可见 | 记忆星图、涟漪控制台让人格内部状态可被理解 |

## 棱镜记忆系统

棱镜记忆系统不是简单的记忆列表，而是**多种记忆层协同工作**的本地记忆架构。

### 五层记忆架构

| 层级 | 职责 | 数据源 |
|------|------|--------|
| **分类事实记忆** | 长期稳定事实：身份、职业、偏好、项目、技能 | 自动提取 + 用户指令 |
| **五元组知识图谱** | 实体关系建模：人物、地点、组织、项目、事件 | 提取 + 用户确认 |
| **语义记忆检索** | 中文 embedding 向量索引，相似度 + 质量 + 时间召回 | 向量数据库 |
| **当前状态** | 有时效信息：生病、短期计划、所在地 | 对话 + 工具结果 |
| **工作记忆** | 当前话题、未闭环问题、临时任务摘要 | 对话上下文 |

### 分类事实记忆

负责保存不应随上下文窗口消失的内容。事实分为**个人资料、偏好、事件、知识、行为和技能**等类别，并记录创建时间、更新时间、来源渠道、来源消息和证据片段。

- 支持用户明确纠正更新旧事实
- 发现矛盾内容时生成冲突候选
- 来源追溯可查看记忆来自哪次对话
- 用户可搜索、修改、删除和清理记忆

### 五元组知识图谱

将人物、地点、组织、项目、作品、兴趣和事件建模为可连接的实体，用**"主体—关系—客体"**保存结构化联系，并保留实体类型、关系来源和强度。

> 分类事实适合表达"用户是一名算法工程师"，图谱则适合表达"用户—参与—无人机基站巡检项目"、"项目—使用—视觉算法"等关联。

### 语义记忆检索

使用中文 embedding 建立向量索引，结合**相似度、记忆质量、更新时间、访问情况和证据数量**进行召回。即使用户换一种说法，也能找到语义相近的过往信息。

### 当前状态与工作记忆

- **当前状态**：保存有时效信息，记录有效期、置信度和状态事件，过期自动结束
- **工作记忆**：保存当前话题和临时任务，默认不升级为永久事实
- **历史会话**：聊天记录独立保存，可按关键词、时间范围和渠道回顾

### 后台记忆维护

后台定期执行记忆维护、冲突候选扫描、低质量内容整理、过期状态清理、来源补全和叙事整合。用户可在设置面板中关闭自动提取、调整间隔、设置上限和暂停维护。

## 涟漪情感系统

涟漪情感系统 v3 是莲心的**连续状态层**，不是给回复贴"开心/难过"标签，而是维护一组受输入、活动、时间和长期关系缓慢影响的动力变量。

### 五轴状态

| 轴 | 含义 | 数值范围 |
|----|------|----------|
| 连接需求 | 保持互动和陪伴的动力 | 0 → 1 |
| 沉浸度 | 对话题、任务或活动的投入程度 | 0 → 1 |
| 防御感 | 面对边界、冲突或不确定输入时的谨慎程度 | -1 ← 0 → 1 |
| 情绪基调 | 表达偏积极或消极的方向 | -1 ← 0 → 1 |
| 唤醒度 | 表达的活跃、紧张或兴奋程度 | -1 ← 0 → 1 |

### 动力学机制

- **事件评估**：每轮交互前评估用户消息，交互后记录结果
- **状态衰减**：情感变量随时间缓慢衰减和恢复
- **事件冷却**：避免短时间频繁触发相同类型事件
- **人格边界**：情感变化受当前人格约束

### 作用边界

涟漪情感会影响语气、回复温度、主动动机和活动选择，但**不会**：

- 代替事实记忆
- 改变当前人格身份
- 阻止正常工具调用
- 绕过权限、安全和隐私规则

控制台提供事件日志、状态变化原因、历史快照、模拟事件和状态恢复入口。

## 人格枢控系统

人格枢控系统让莲心的**"身份"和"状态"分离管理**。人格档案描述她是谁、如何称呼用户、如何表达以及哪些行为边界不可越过；记忆和情感状态由独立的运行时层维护。

### 功能特性

- 创建和编辑人格档案
- 设置称呼、性格、关系、表达边界和语气
- 预览人格提示词并校验字段
- 保存并热激活人格
- 选择从下一条消息生效，或新建干净会话

每次请求使用稳定的人格快照，避免在工具调用过程中途改变身份。激活前的预览和校验用于检查必填字段、身份一致性和表达边界。

## AI 主动意识

莲心的主动聊天不是简单的定时器，而是由**主动行为调度器、涟漪状态、当前话题、用户空闲时间、冷却规则和后台职责**共同决定的智能系统。

### 主动行为类型

| 行为 | 说明 |
|------|------|
| 主动聊天 | 根据时间、空闲程度和状态发起对话 |
| 随机提问 | 分享想法或延续未闭环话题 |
| 桌面观察 | 截图观察并汇报看到的内容 |
| B 站冲浪 | 选择视频并发送标题和链接 |
| 摸鱼 | 天气碎碎念、系统状态、日记回顾、音乐和提醒 |

### 调度机制

1. 判断当前是否适合打扰
2. 从候选行为中选择一个动作
3. 执行行为并生成回复
4. 进入冷却和去重逻辑
5. 用户输入优先，自动让路

所有主动行为可在后台职责中心查看、暂停、恢复和调试。

## 工具、视觉与语音

### 工具能力

莲心通过统一工具层调用多种能力，工具执行具有**资源分组、超时、重试、重复调用检测、权限拦截和错误回传**机制。

| 类别 | 工具 |
|------|------|
| 信息查询 | 天气、时间、CPU、内存、磁盘、系统信息 |
| 文件操作 | 文件读取、搜索、差异查看、代码诊断 |
| 浏览器 | 导航、快照、点击、填写、网页获取 |
| 视觉 | 截图、摄像头、OCR、图像描述、图像生成 |
| 生活助手 | 日记、备忘、待办、提醒、任务追踪 |
| 娱乐 | 音乐播放、暂停、切歌、播放状态查询 |
| 记忆 | 保存、搜索、更新、冲突处理、来源追溯 |

### 视觉理解

支持截图分析、摄像头观察、OCR、图片描述和图像生成。可使用 **SiliconFlow** 等云端视觉接口，也可根据配置接入本地模型。

### 语音交互

| 能力 | 方案 |
|------|------|
| 语音输入 | 本地 FunASR / Whisper，或阿里云、火山引擎云端识别 |
| 全双工语音 | WebRTC VAD 检测说话与停顿，支持耳机模式和打断 |
| 语音输出 | Edge-TTS 默认回退，GPT-SoVITS 自定义声线和情绪化表达 |
| 参考音频 | 按语气选择对应音色 |

## 快速开始

### 1. 创建环境

建议使用 Conda 和 Python 3.12：

```powershell
conda create -n lianxin python=3.12
conda activate lianxin
pip install -r requirements.txt
```

### 2. 配置模型

启动后在设置界面配置，或编辑用户配置文件：

```text
%USERPROFILE%\.lianxin\user_config.json
```

至少需要配置一个可用的文本模型。项目支持 DeepSeek、Agnes、OpenAI 兼容接口和 Ollama。

```json
{
  "deepseek": {
    "api_key": "你的 API Key",
    "base_url": "https://api.deepseek.com",
    "model": "deepseek-v4-flash",
    "provider": "deepseek"
  }
}
```

### 3. 启动

```powershell
conda activate lianxin
python main.py
```

### 可选配置

| 服务 | 说明 |
|------|------|
| Ollama 本地模型 | 启动 Ollama 并下载模型，配置 provider 为 local |
| SiliconFlow 视觉 | 配置 API Key 启用截图分析和摄像头观察 |
| GPT-SoVITS 语音 | 部署 GPT-SoVITS 服务并配置参考音频 |
| QQ 桥接 | 配置 WebSocket 地址和 owner_qq |
| 微信桥接 | 通过 AstrBot 接入微信消息 |

## 数据与隐私

### 数据存储

| 数据类型 | 存储位置 | 格式 |
|----------|----------|------|
| 用户配置 | `%USERPROFILE%\.lianxin\user_config.json` | JSON |
| 会话记录 | `memory/` 目录 | SQLite |
| 记忆数据 | `memory/` 目录 | SQLite + JSON |
| 情感状态 | `memory/` 目录 | SQLite |
| 日志文件 | `logs/` 目录 | 文本 |

### 隐私保护

- 所有记忆、情感和配置数据**本地存储**，不主动上传
- 用户配置、API Key、Cookie 和记忆数据库**不应提交到 Git**
- 工具调用有权限边界，不会无条件执行危险操作
- 记忆写入包含来源消息和时间范围，可追溯和审计

## 开发与测试

### 开发建议

1. 保持代码风格与现有模块一致
2. 新增功能时考虑权限边界和错误恢复
3. 后台任务不应阻塞正常聊天
4. 记忆操作保留原始数据，不破坏已有内容

### 测试检查

- [ ] 用户配置、API Key、Cookie、记忆数据库和日志未提交到 Git
- [ ] 工具调用失败时仍能给出可理解的回复
- [ ] 主动行为遵守暂停、冷却和用户输入优先原则
