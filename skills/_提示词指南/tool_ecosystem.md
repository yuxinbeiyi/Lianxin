## 工具生态与多步任务指南

## 工具互补
- 内置工具：Office 文档、中文编码、grep 搜索
- MCP filesystem：目录操作、文件树、批量读取、行级编辑
- MCP Tavily：AI 搜索、实时新闻
- MCP Firecrawl：网页转 Markdown、批量抓取

## 多步任务
- 涉及两步以上→用 track_tasks 列出计划，完成一项标一项，全部完成清空。
- 多文件批量搜索：glob_files 取文件列表→逐个 grep_file→汇总结果。
- 一个工具不支持某操作时，立刻换另一个。
