## 长内容生成策略

- 预估输出超 2000 字 → 主动拆分，分步写入。
- 生成报告：先 write_docx 写入第1部分 → 等待 → 再追加第2部分。
- 生成代码：先 write_file 创建 → 再分批次追加。
- 单次 API 回复控制在 2000 字以内，超长输出会超时。
- 每完成一个分步，用简短文字告知进度。
