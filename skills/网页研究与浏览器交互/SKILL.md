# 网页研究与浏览器交互

这是一个任务编排技能，不新增网络请求工具，也不替换 `web_search`、
`fetch_webpage` 或浏览器工具。它只在用户明确提出“搜索后打开/阅读/操作”
时生效，并要求执行层按以下顺序运行：

1. 调用 `web_search` 获取候选来源和原始链接。
2. 根据用户目标选择最相关的原始 URL。
3. “阅读/总结正文”使用 `fetch_webpage`；“打开/点击/填写/操控”使用浏览器工具。
4. 浏览器页面变化后重新获取快照，不能复用过期的 `snapshot_id` 或 `ref`。
5. 最终回答只能引用真实工具结果；搜索摘要不能冒充网页正文，计划性话术不能冒充完成。

## 任务边界

- 用户只说“搜索/查资料”：只调用 `web_search`，不自动打开浏览器。
- 用户只给 URL 并要求读取：使用 `fetch_webpage`，不自动搜索。
- 用户明确要求接管已经打开的浏览器：搜索完成后先调用 `browser_connect`，只允许本机 loopback CDP。
- 点击、输入、提交、登录等高风险动作继续遵守浏览器技能的逐步确认策略。
