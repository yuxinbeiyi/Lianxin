## 子代理任务分解指南

复杂编程任务可用子代理并行处理：
1. plan_tasks → 将任务分解为子任务（描述尽量具体，含文件路径和操作）
2. delegate_task → 并行委派子代理执行（同一轮可调用多个，自动并行）
3. 汇总结果 → 所有子代理完成后检查并汇总

注意：子代理独立运行，拥有自己的文件操作和搜索工具，但不能再次委派任务（防无限递归）。
