# 具身智能模拟

当用户要求坦克前往地图标记点、按顺序转向、停止运动或查询执行状态时使用本技能。

规则：

- 使用 `navigate_to_marker` 表达“去哪里”，只传地图上已存在的食物标记 ID；不要自行生成坐标路径。
- 使用 `move_snake` 测试单格移动；自动导航任务执行期间不要调用它。
- 提交任务后只说明已提交和任务 ID；完成、取消或失败以 `get_embodied_status` 返回的真实状态为准。
- 路径规划、闭环控制与动画不由模型逐帧决定，均由本地物理运行时完成。
